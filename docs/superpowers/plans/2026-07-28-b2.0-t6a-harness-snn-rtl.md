**Goal:** provare in xsim che il **VHDL generato** di `Donatello_Tier@BALANCED` riproduce **bit-exact il blocco**
sul dataset dei **60**, con cancelli provati sensibili, e riportare l'accuratezza di stima dei 5 param sugli **stessi
60**, il tutto **rilanciabile da un comando**. (L'hardware — utilizzo post-route, power, bitstream — è il piano **T6b**.)

**Architecture:** MATLAB calcola **una volta** il golden dei 60 **dal blocco stesso** (oracolo) e lo mette in cache;
la cache alimenta **sia** l'export dei vettori `.mem` per xsim **sia** le metriche → i due si riferiscono per
costruzione agli stessi identici dati. Un TB VHDL pilota il DUT in xsim, **una simulazione per traiettoria**.
Un entry-point unico esegue tutto e **salva i risultati su disco**.

**Tech Stack:** MATLAB R2026a headless (`"C:\Program Files\MATLAB\R2026a\bin\matlab.exe" -batch`) · HDL Coder
`makehdl` · Vivado 2026.1 `xvhdl/xvlog/xelab/xsim` · Git-Bash per il runner.

## §0 Requisiti vincolanti (violati alla prima esecuzione — NON ri-violare)

1. **RIPRODUCIBILITÀ.** L'harness deve essere **rilanciabile da chiunque con UN comando**, e i numeri devono vivere
   in **artefatti su disco** (`results/*.mat` + `results/RESULTS.md`), non in una chat o in invocazioni ad-hoc.
   Il README documenta: il comando singolo, i prodotti, il runtime atteso. La **configurazione misurata** (blocco,
   variante, nfrac, hold, dataset, latenza) va salvata **insieme** ai numeri.
2. **STESSO PERIMETRO per prova e metriche.** Se le metriche sono sui 60, la **prova RTL è sui 60**. Un subset è
   legittimo **solo** come gate rapido di sviluppo (`mode='smoke'`), **mai** come base dei numeri riportati:
   popolazioni diverse ⇒ numeri non appaiabili ⇒ lo scostamento RTL↔riferimento non è leggibile, nemmeno se è 0.
   Corollario: **golden calcolato UNA volta** e consumato da entrambi (correttezza, oltre che costo).
3. **Niente ripieghi in corsa per risparmiare tempo.** Se un job corretto è lungo, si lancia in background e **si
   lascia finire**. Il tempo "risparmiato" torna come rilavorazione.

**Convenzioni:** commit conventional **senza** `Co-Authored-By`; stage **esplicito** (mai `git commit -am`; i
`*.mexw64` sono tracciati); non toccare `matlab/closed_loop_demo.slx` / `matlab/slblocks.m`. Cancelli: assert +
**prova di sensibilità**. **Core SNN congelato; VHDL mai a mano.**

### Le 4 lezioni HDL (già incorporate nel codice — non ri-scoprirle)
1. **Blocco mascherato**: `find_system` **non guarda sotto la mask** → per un Variant Subsystem servono
   `get_param(blk,'Ports')` e **`save_system` prima dell'`update`** (risolve la variante). Senza: *"unable to
   determine sizes/types"*.
2. **Ordine di compilazione VHDL**: **bottom-up**, letto dal **log di `makehdl`** (`pkg → DEC → DualPortRAM → SNN →
   BALANCED_n13 → VS → Donatello_Tier`). Alfabetico o per `datenum` **non funziona** (gerarchia profonda).
3. **Lo stato SNN vive nella `hdl.RAM` (DualPortRAM)**: il segnale `reset` a runtime **non la azzera** — solo l'init
   di una simulazione. → **una simulazione xsim per traiettoria** (il runner compila una volta e cicla).
4. **Fix senza root cause = tempo perso**: il "reset per-traiettoria" è stato applicato prima di capire (3) e non ha
   funzionato (4996/10000). Prima il meccanismo, poi il fix.

### Difetti di metodo da sanare (→ §B)
- **D1** i numeri sono stati prodotti da **invocazioni ad-hoc**, non da un entry-point → viola §0.1.
- **D2** prova RTL su **11** ma metriche su **60** → viola §0.2 (perimetri diversi ⇒ non appaiabili).
- **D3** il golden veniva ricalcolato **due volte** (~28 min sprecati) → viola §0.2 (corollario) e §0.3.

```matlab
function [P, meta] = tier_golden_cache(trajList, force)
%TIER_GOLDEN_CACHE  Golden del blocco Donatello_Tier@BALANCED calcolato UNA VOLTA e riusato: la stessa cache
%  alimenta l'export dei vettori RTL e le metriche -> i due si riferiscono agli STESSI identici dati (§0.2).
%  Salva golden_tier_bal.mat accanto a questo file, con la CONFIGURAZIONE misurata (per tracciabilita').
%  force=true ricalcola ignorando la cache. Ritorna P{i} = Ni x 5 (double) e meta (config + latenza).
  if nargin<1 || isempty(trajList), trajList = 1:60; end
  if nargin<2 || isempty(force),    force = false;  end
  here  = fileparts(mfilename('fullpath'));
  cfile = fullfile(here, 'golden_tier_bal.mat');
  cfg = struct('block','Donatello_Tier', 'tier','BALANCED', 'nfrac_param',13, ...
               'hold',500, 'nfrac_in',20, 'dataset','test_dataset.mat');
  if ~force && exist(cfile,'file')
    S = load(cfile);
    if isequal(S.meta.cfg, cfg) && all(ismember(trajList, S.meta.trajList))
      [~, loc] = ismember(trajList, S.meta.trajList);
      P = S.P(loc); meta = S.meta; meta.trajList = trajList; meta.fromCache = true;
      fprintf('tier_golden_cache: cache HIT (%d traj) <- %s\n', numel(trajList), cfile);
      return
    end
    fprintf('tier_golden_cache: cache MISS (config o traiettorie diverse) -> ricalcolo\n');
  end
  t0 = tic;
  [P, lat] = tier_block_params(trajList, cfg.hold, cfg.nfrac_in);
  meta = struct('cfg',cfg, 'trajList',trajList, 'lat',lat, 'secs',toc(t0), ...
                'built', datestr(now,'yyyy-mm-dd HH:MM:SS'), 'fromCache',false);
  save(cfile, 'P', 'meta');
  fprintf('tier_golden_cache: calcolato %d traj in %.1f min (lat=%d) -> %s\n', ...
          numel(trajList), meta.secs/60, lat, cfile);
end
```

```matlab
function R = run_harness_snn(mode)
%RUN_HARNESS_SNN  Entry-point UNICO dell'Harness_SNN (Fase B2.0 T6a): esegue l'intera catena e salva i risultati.
%  Uso:  matlab -sd <questa cartella> -batch "run_harness_snn"          % default 'full' (i 60, numeri riportabili)
%        matlab -sd <questa cartella> -batch "run_harness_snn('smoke')" % gate rapido di sviluppo (subset)
%  Catena: VHDL (se assente) -> golden in cache -> T6-EXACT -> sensibilita -> metriche -> results/.
%  Prodotti: results/harness_snn_results.mat + results/RESULTS.md (tabella leggibile). Runtime 'full' ~75 min.
  if nargin<1 || isempty(mode), mode = 'full'; end
  here = fileparts(mfilename('fullpath'));
  addpath(fullfile(here,'..','..','matlab')); addpath(fullfile(here,'..','common'));
  outdir = fullfile(here,'results'); if ~exist(outdir,'dir'), mkdir(outdir); end
  t0 = tic;
  fprintf('=== HARNESS_SNN [%s] — Donatello_Tier@BALANCED ===\n', mode);

  % 1) golden in cache (calcolato una volta; le metriche useranno GLI STESSI dati)
  if strcmp(mode,'full'), trajList = 1:60; else, trajList = []; end   % [] -> subset diversificato
  [~, gmeta] = tier_golden_cache(iff(isempty(trajList), 1:60, trajList));

  % 2) T6-EXACT + LAT (un xsim per traiettoria)
  rtl = run_rtl_validate_tier(mode, trajList);

  % 3) sensibilita (il cancello deve poter fallire)
  sens = sensitivity_t6();

  % 4) metriche di stima sugli STESSI dati del confronto RTL
  M = tier_rtl_metrics(rtl.trajListUsed);

  R = struct('mode',mode, 'rtl',rtl, 'sens',sens, 'metrics',M, 'golden',gmeta, ...
             'when',datestr(now,'yyyy-mm-dd HH:MM:SS'), 'secs',toc(t0));
  save(fullfile(outdir,'harness_snn_results.mat'), '-struct', 'R');
  write_results_md(fullfile(outdir,'RESULTS.md'), R);
  fprintf('\n=== HARNESS_SNN COMPLETATO in %.1f min -> results/ ===\n', R.secs/60);
end

function y = iff(c,a,b), if c, y=a; else, y=b; end, end

function write_results_md(f, R)
  fid = fopen(f,'w');
  w = @(varargin) fprintf(fid, varargin{:});
  w('# Harness_SNN — risultati (T6a)\n\n');
  w('Generato da `run_harness_snn(''%s'')` il %s (runtime %.1f min).\n\n', R.mode, R.when, R.secs/60);
  w('## Configurazione misurata\n\n');
  c = R.golden.cfg;
  w('| parametro | valore |\n|---|---|\n');
  w('| blocco | `%s` @ TIER=%s, NFRAC=%d |\n', c.block, c.tier, c.nfrac_param);
  w('| ingressi | `fixdt(1,32,%d)` · hold %d clock |\n', c.nfrac_in, c.hold);
  w('| dataset | `%s` — %d traiettorie |\n', c.dataset, numel(R.rtl.trajListUsed));
  w('| latenza blocco | %d clock |\n\n', R.golden.lat);
  w('## Cancelli\n\n| cancello | esito | numeri |\n|---|---|---|\n');
  w('| T6-EXACT (RTL == blocco) | %s | nMismatch %d / %d (%d traj x %d step x 5 param) |\n', ...
    pf(R.rtl.nMismatch==0), R.rtl.nMismatch, R.rtl.n, R.rtl.traj, R.rtl.K);
  w('| LAT (misurata < HOLD) | %s | %d clock (HOLD %d) |\n', pf(R.rtl.lat>0 && R.rtl.lat<c.hold), R.rtl.lat, c.hold);
  w('| Sensibilita (1 LSB) | %s | nMismatch %d (atteso >=1) |\n', pf(R.sens>=1), R.sens);
  w('| PORT-TYPE | %s | coperto da T6-EXACT (tipo errato => mismatch sistematico) |\n\n', pf(R.rtl.nMismatch==0));
  w('## Accuratezza di stima (versione FPGA == blocco)\n\n| param | max | p99 |\n|---|---|---|\n');
  nm = fieldnames(R.metrics);
  for i=1:numel(nm), w('| %s | %.4g | %.4g |\n', nm{i}, R.metrics.(nm{i}).max, R.metrics.(nm{i}).p99); end
  w('\n`v0` alto = **identificabilita** (osservabile a flusso libero), non difetto RTL. La qualita car-following e il closed-loop (T7).\n');
  fclose(fid);
end
function s = pf(ok), if ok, s='**PASS**'; else, s='**FAIL**'; end, end
```
